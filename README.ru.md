# NeoCalc — калькулятор Windows с 26 темами и полной настройкой оформления

[Español](README.md) · [English](README.en.md) · [Português](README.pt.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Italiano](README.it.md) · [Polski](README.pl.md) · **Русский** · [한국어](README.ko.md) · [日本語](README.ja.md)

Обычный и инженерный калькулятор для **Windows 10 и 11**, который работает как калькулятор Windows, но с
**26 встроенными темами** и редактором для создания своих: цвета, градиенты, фоновое изображение, шрифты,
круглые клавиши, неоновое свечение, LCD-дисплей… Один файл `.exe` размером около 200 КБ, без установки.

**Сайт:** https://divolandialabs.github.io/neocalc/ · **Скачать:** [последняя версия](https://github.com/DivolandiaLabs/NeoCalc/releases/latest)

![NeoCalc в инженерном режиме с темой «Кибер-неон»](docs/screenshots/en-cientifica.png)

## Возможности

- **Обычный режим** точно как в калькуляторе Windows: действия выполняются по цепочке (3 + 5 × 2 = 16), `=` повторяет последнее действие, а `%` работает так же.
- **Инженерный режим** с приоритетом операций и скобками (3 + 5 × 2 = 13), `2nd`, DEG/RAD/GRAD, экспоненциальная запись (F-E), тригонометрия, логарифмы, степени, корни, `n!` (в том числе для дробных), `mod` и `exp`.
- **Журнал и память** (MC, MR, M+, M−, MS): в боковой панели, если окно широкое, или поверх клавиш, если узкое.
- **Любой размер**: потяните за угол — весь калькулятор увеличится или уменьшится; кнопка **Закрепить этот размер** сохранит его для следующих запусков.
- **Полная поддержка клавиатуры**, копирование и вставка, кнопка **Поверх всех окон**.
- **26 тем**: Windows тёмная и светлая, Кибер-неон, Synthwave, Matrix, Ретро-LCD, Янтарный терминал, Дракула, Северная, Game Boy, Голограмма, Стекло, Круглая (в стиле iPhone), Золото и чёрный, Vaporwave…
- **Редактор тем** с мгновенным предпросмотром, выбором цвета с прозрачностью, кнопкой **Случайная** и **импортом/экспортом** тем (`.neocalc.json`).
- **Значок на панели задач** в цветах темы, даже когда программа закреплена.
- **10 языков**: испанский, английский, португальский, французский, немецкий, итальянский, польский, русский, корейский и японский.

## Установка

1. Скачайте `NeoCalc.exe` со [страницы релизов](https://github.com/DivolandiaLabs/NeoCalc/releases/latest).
2. Сохраните файл в любом месте (например, `Документы\NeoCalc`) и запустите. Установка не нужна.
3. Чтобы программа была под рукой: щёлкните правой кнопкой по её значку на панели задач → **Закрепить на панели задач**.

При первом запуске Windows SmartScreen может показать предупреждение, так как программа не подписана: нажмите **Подробнее → Выполнить в любом случае**.

Чтобы удалить программу, достаточно удалить `.exe` и, при желании, папку `%APPDATA%\NeoCalc`.

## Темы и оформление

Откройте редактор кнопкой с палитрой 🎨 или сочетанием **Ctrl+T**. Выбранная тема применяется сразу; если изменить что-то во
встроенной теме, в разделе **Мои темы** появится копия, а оригинал не изменится.

![Редактор тем](docs/screenshots/en-temas.png)

Можно настроить: цвета фона (градиент и угол), фоновое изображение, непрозрачность окна, углы, фон и цифры дисплея, рамку в
стиле LCD, цвета каждого типа клавиш, шрифты и их насыщенность, размер текста, скругление клавиш (вплоть до круглых),
расстояние между ними, обводку и неоновое свечение.

## Сочетания клавиш

| Клавиша | Действие |
|---|---|
| `0`–`9`, `,` `.` | Ввод чисел |
| `+` `-` `*` `/` `Enter` | Операции / равно |
| `Backspace` · `Delete` · `Esc` | Удалить цифру · CE · C |
| `F9` · `R` · `@` · `Q` | +/− · 1/x · корень · x² |
| `(` `)` `^` `!` `%` | Скобки, степень, факториал, mod (инженерный) |
| `Alt+1` · `Alt+2` | Обычный · Инженерный |
| `Ctrl+M` `Ctrl+R` `Ctrl+P` `Ctrl+Q` `Ctrl+L` | MS · MR · M+ · M− · MC |
| `Ctrl+H` · `Ctrl+T` | Журнал · Темы |
| `Ctrl+C` · `Ctrl+V` | Копировать · Вставить |

## Сборка из исходного кода

Ничего устанавливать не нужно: программа собирается компилятором C#, который уже есть в Windows (.NET Framework 4.8).

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Значок рисует сама программа (`src\Icono.cs`). Проверка вычислительного ядра: `NeoCalc.exe /prueba result.txt`.

## Конфиденциальность

NeoCalc никогда не подключается к интернету и не собирает никаких данных. Настройки, журнал и ваши темы хранятся только на
вашем компьютере, в `%APPDATA%\NeoCalc\config.json`.

## Требования

Windows 10 или 11 (включает .NET Framework 4.8).
